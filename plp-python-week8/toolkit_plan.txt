1. TOOLS CHOSEN (4 tools):

Tool 1: To-Do List Manager
- What it does: Lets user add, view, and remove tasks. The list grows and shrinks while program runs.

Tool 2: Number Guessing Game  
- What it does: Computer picks random number 1-50, user guesses until correct with hints.

Tool 3: Simple Calculator
- What it does: Takes two numbers and an operator (+ - * /) and shows result.

Tool 4: Countdown Timer
- What it does: Counts down from user-given seconds to 0.
